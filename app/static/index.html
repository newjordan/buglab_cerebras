    BugLab v0.1.0

    BugLab is rapid recursive bug hunting featuring Ponytail, the DELI R&D method, and Cerebras Inference with Gemma-family models where configured.

    Rapidly comb the codebase for issues, generate a report, and run basic patch/fix loops. Rapid information, and bug hunting.
